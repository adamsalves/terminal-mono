{{- /* A list-shaped param, normalised. Two separate things go wrong with these, and a truthiness test catches neither. The list itself may not be a list — `items = "x"` reaches a `range` and takes the build down. And a list may hold the wrong kind of entry: `items = ["a", "b"]` ranges fine and then dies on the `.repo` of the first string, halfway through rendering. There is a quieter version of the first. `first` does not reject a string, it slices its *bytes*: {{ delimit (first 6 "Go") " · " }} → 71 · 111 so a truthiness guard on a param that should be a list is not enough — the wrong type ships as plausible-looking garbage instead of failing where a consumer would see it. That is why this checks reflect.IsSlice rather than merely `if`. Context: dict "value" "path" "" "maps" . Returns a list, empty if the param was not one. Entries that are dropped are counted and reported. A typo that silently removes one project from a list of six is worse than one that fails, and the count is the only part of that a consumer can act on. */ -}} {{- $out := slice -}} {{- $v := .value -}} {{- if reflect.IsSlice $v -}} {{- if .maps -}} {{- $dropped := 0 -}} {{- range $v -}} {{- if reflect.IsMap . -}} {{- $out = $out | append . -}} {{- else -}} {{- $dropped = add $dropped 1 -}} {{- end -}} {{- end -}} {{- with $dropped -}} {{- warnf "terminal-mono: %s ignored %d of its entries — each one must be a table, not a bare value" $.path . -}} {{- end -}} {{- else -}} {{- $out = $v -}} {{- end -}} {{- else -}} {{- with $v -}} {{- warnf "terminal-mono: %s must be a list, got %#v — ignoring it" $.path . -}} {{- end -}} {{- end -}} {{- return $out -}}
